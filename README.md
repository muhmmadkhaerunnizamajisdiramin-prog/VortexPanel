# Vortex Panel

Game Performance Booster (Black + Green Theme)

**Package:** `com.vortexpanel`

## Cara Build APK dari HP (GitHub Actions)

1. Upload semua file project ini ke repository GitHub kamu
2. Buka repository → tab **Actions**
3. Pilih workflow **Build APK**
4. Tekan **Run workflow**
5. Tunggu proses build selesai
6. Download file APK dari bagian **Artifacts**

## Fitur Saat Ini

- Status Shizuku real-time
- One-Tap Boost
- Info RAM
- Tema hitam + hijau modern
- Integrasi Shizuku dasar
